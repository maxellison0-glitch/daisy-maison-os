# Daisy Maison Personas

The characters who front Daisy Maison's social content: **Max**, the real
founder; **Freya**, a proposed social/creative-lead character to be built
as a consistent Higgsfield identity; and **Alan**, an already-generated
synthetic male character used as the account's main male presence until an
accurate synthetic-Max build exists.

This folder is the planning layer — who they are, how they sound, how they
get built. Producing an actual piece of content still runs through the
existing `Content Pipeline/Creative Studio` process once it's briefed.

## Start here

1. `MAX.md` — the real founder's on-camera voice and content role. Already
   true, not proposed. Also covers the correction that led to Alan existing
   as a separate character — read this before assuming any synthetic male
   content is an accurate likeness of Max.
2. `FREYA.md` — the proposed second character: full identity, voice,
   positioning, appearance spec. **Not yet approved** — read this and
   confirm or redirect the name/direction before anything is built.
3. `ALAN.md` — the adopted main male character, recast from what was
   originally an attempted synthetic-Max likeness that didn't hold up.
   Deliberately lightly defined — a placeholder character, not a deep
   investment, until Max decides otherwise.
4. `VOICE_AND_CAPTION_GUIDE.md` — the shared caption and tone playbook
   characters write from. Usable immediately, no approval needed — it's a
   writing standard, not a creative commitment.
5. `HIGGSFIELD_CHARACTER_BUILD.md` — the accurate, staged workflow to
   actually build a consistent Higgsfield Soul character, written for
   Freya but the same process for any future build (including a proper
   synthetic Max, if that's ever wanted). Phased and credit-conscious;
   nothing in it should run unattended.

## Working model (confirmed by Max, 24 July 2026)

Alan and Freya are partnered as the on-camera creative pair for sign
content: both have validated stills workflows for the Large street sign
(`Creative Studio/SIGN_CAPABILITIES.md`), Alan additionally has the
validated wedding-sign video method. Real Max fronts real
behind-the-scenes. Winning past posts get remade through this pair — see
`Content Pipeline/REFERENCE_WINNERS.md`.

## Why this exists

Creative Studio already proves Daisy Maison can make excellent AI-assisted
product video — see DM-C017's validated wedding-sign turn. What was missing
was a *person*: someone whose voice writes the captions and decides what
gets posted, the way a real social media manager would. Max fronts the
craft/trust side of the account; Freya (proposed) fronts the taste/curation
side. Neither replaces the other — see each file for their distinct content
roles.
