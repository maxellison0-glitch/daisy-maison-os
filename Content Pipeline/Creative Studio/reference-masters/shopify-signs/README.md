# Shopify Sign Reference Library

**These are the real product photos from the live Shopify store.** Every image
here shows the correct sign shape, correct colourway, correct proportions.

Downloaded 24 Sep 2026 from the Shopify CDN. Max's rule: use these as the
literal image reference inside Higgsfield every time. Do not generate a sign
from a text description — use the real photo.

## How to use

### Sign on its own (no human)
Use the Shopify product photo directly as the image reference. The sign shape,
colourway and proportions are already correct — the generation only needs to
change the wording on the sign.

### Sign with a human presenter
Two references required:
1. **Sign reference**: the Shopify product photo from this folder
2. **Human reference**: the character lock (ALAN-LOCK or FREYA-LOCK)

Never generate with only a human reference and no sign reference. The sign
reference is what keeps the shape accurate.

## Shape accuracy gate

The real product is a **scalloped street sign** — curved/shaped ends, NOT a
rectangle. If a generation produces:
- A rectangular sign → REJECT
- A sign with wrong proportions (too wide, too tall, wrong aspect) → REJECT
- A sign with mounting holes → REJECT
- A sign in a colourway that doesn't exist → REJECT

The five real colourways: BLACK, GREY, SAGE, GRASS, BLUE (all on cream panel
#F2EEE3). Nothing else exists.
