# Daisy Maison creative recipes

This folder stores production knowledge that has survived Max's visual review.
It is portable with Creative Studio and must be read by any agent before using
Higgsfield or another generative production tool.

## What belongs here

- exact prompts and model settings behind Max-approved assets;
- every source/reference image and its role;
- generation, media and job IDs;
- the selected output and Max's reason for choosing it;
- nearby failed variants only when they teach a reusable constraint;
- a product identity sheet: real dimensions, construction, wording and visual
  invariants that a generation must not change.

## What does not belong here

- invented reconstructions of missing prompts;
- agent-only aesthetic approval presented as Max approval;
- raw chat transcripts;
- every failed image from an exploratory batch;
- generic prompt advice without a proven Daisy Maison output.

## Required production loop

1. Start from a proven recipe or clearly label the work experimental.
2. Prepare references, prompt and controlled variables before generation.
3. Generate a contact-sheet batch, normally 6-10 still candidates when the
   available subscription makes that sensible.
4. Agents reject obvious technical failures but do not choose Max's winner.
5. Max selects a candidate or rejects the batch.
6. Record his feedback as an explicit next-batch constraint.
7. Promote only a Max-approved still into image-to-video testing.
8. Save the winning video prompt/take with the same provenance.

The system automates provenance, preparation, batches, contact sheets, logging
and assembly. Max remains the creative director and global product-realism gate.
