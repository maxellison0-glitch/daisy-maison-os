# Daisy Maison Creative Studio

This is the permanent Jarvis home for Daisy Maison social content and adverts.
Open this folder in Claude or Codex whenever you want to resume creative work.

## Resume in 60 seconds

1. Read `CURRENT.md` for the one active job and next action.
2. Read `MEMORY.md` for what worked, what is parked and what we learned.
3. Read `recipes/README.md` before any generative production.
4. Work only inside the active concept folder named in `CURRENT.md`.

## Organisation rule

- `active/` contains the concept currently being made.
- Finished and parked work can remain in the original Content Pipeline; this
  studio records its exact path instead of duplicating large exports.
- One active concept at a time unless Max explicitly opens a second lane.
- Every session ends by updating `CURRENT.md` with the latest accepted decision
  and one physical next action.

This folder is intentionally simple. The older `Content Pipeline` remains the
production archive; this is the front door.
