# Wedding-sign workflow GitHub package

This is the compact, transferable Jarvis package for the validated **Wedding
Sign Engineering Prompt Workflow**.

## Included

- canonical workflow, video rules and living context;
- validated and rejected prompt cases;
- approved product, synthetic-Max endpoint and white-reverse evidence;
- exact SVG/PNG/PDF assets;
- four-view real Daisy Maison construction references;
- original reference turn and privacy-cropped motion input;
- generation prompts, settings, scripts, IDs, costs and approval records;
- untouched validated Seedance result;
- finished master, phone preview, browser player and delivery verification;
- all-frame overview, nine all-frame sheets and readable-lettering comparison
  pages;
- reusable white-wedding-sign scaffold with its explicit product-family gate.

## Deliberately local-only

- duplicate caches and temporary files;
- 193 individually decoded native frames;
- 300 individually extracted Instagram reference frames;
- rejected intermediate batches already represented by the documented failure
  case and selected evidence;
- experimental exports that are not inputs to the validated workflow.

Those omitted frame collections are reproducible from the included source
videos and QC scripts. They are excluded to keep Git synchronization practical,
not because the validation evidence is incomplete.

## Scope boundary

This package proves only the white Daisy Maison wedding-sign family demonstrated
by DM-C017 Jannaway v03. It does not prove:

- coloured signs with black text;
- coloured signs with coloured text;
- non-wedding sign families.

Each future family must earn its own complete human-approved image and native
video case before being promoted.

Nothing in this package is publishing approval.
