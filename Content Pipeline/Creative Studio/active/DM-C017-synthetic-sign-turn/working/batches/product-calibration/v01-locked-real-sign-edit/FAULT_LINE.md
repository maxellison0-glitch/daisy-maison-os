# Fault line and correction

## Failed approach

The V03/V04 prompts split product truth across a flat sign face, several real
angle references and written geometry. The model therefore treated the border
and the sheet edge as design variables. It repeatedly made the black printed
front band too narrow or removed it.

## Correction under test

Use one real Daisy Maison sign photograph as a locked manufactured-object
master. Permit one semantic edit only: change the existing printing to the
supplied LightBurn-derived design. Do not ask the model to reconstruct border,
shape, thickness, material, lighting or hand contact from separate rules.

## Promotion rule

Do not promote this prompt to the reusable prompt library merely because one
still looks acceptable. It must first:

1. pass all product and text checks in an untouched native still;
2. be approved by Max;
3. survive the synthetic-Max image stage;
4. survive a native continuous video turn frame by frame; and
5. produce the finished Reel with hook, hold, CTA, typography and sound.
