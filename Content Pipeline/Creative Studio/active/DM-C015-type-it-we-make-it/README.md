# DM-C015 - Type It. We Make It.

A second street-sign advert built around the strongest truthful asset: Daisy
Maison's exact deterministic SVG renderer.

Unlike DM-C006, this does not replace one surname with another. It constructs
both personalised lines as the viewer watches, making the advert itself feel
like the buying action, then hard-cuts to the matching Potter wedding reveal.

Run:

```powershell
python render.py
```

Outputs are written to `exports/`.
