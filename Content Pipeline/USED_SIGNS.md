# Used Signs — Hard Dedupe Registry

**Read this before every post. If the wording, colourway, name or hook is
already here, pick something else.**

This exists because the system kept repeating itself — same names, same
colourways, same concepts. Max, 24 Sep 2026: "you use the name carters and
blue signs over and over it's shit."

---

## Rules

1. Every sign that ships OR gets rejected goes in the table below.
2. Check this table BEFORE picking a concept — not after.
3. Never reuse a LINE 1 + LINE 2 combo that's already here.
4. Never use the same NAME (e.g. "Carter", "Bond", "Hale") twice.
5. Rotate colourways — never post the same colourway two days running.
   All five real colourways (black, grey, sage, grass, blue) should appear
   before any repeats.
6. Rotate hook structures — never use the same hook template two days running.

## The five REAL colourways (the only ones that exist)

BLACK, GREY, SAGE, GRASS, BLUE. That's it. Navy, burgundy, forest green,
slate were invented and are not products.
