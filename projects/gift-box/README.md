## Collection Rules

- Warm-white field with abundant untouched space.
- Artwork and sentiment sit together in the lower-right area.
- Fine monochrome graphite-and-ink drawing with soft pencil shading.
- Clean printed typewriter-style serif text, never cursive.
- Pebble hearts appear as shaded physical stones, not flat heart icons.
- Every illustration must uniquely reinforce its sentiment while still feeling
  like part of the same Daisy Maison family.
- Do not repeat the original watering-can and potted-tree composition as a new
  variant.
