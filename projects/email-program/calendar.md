# 12-Month Campaign Calendar (UK gifting)

*Cadence rule: max 1–2 campaigns/week, always to `Engaged 90d` unless stated.
Flows run continuously underneath. Every send needs Max's go.*

| When | Campaign | Notes |
|---|---|---|
| **Sep** | "Back to it" new-home angle | House-move season; family street sign hero |
| **Late Sep** | Christmas range teaser | Catalogue carries Christmas year-round; early-bird framing, no discount |
| **Oct** | Christmas personalisation push | "Made to order" = order early framing begins |
| **Nov (w1)** | Christmas gift guide | Segmented: past buyers get "you know the drill" |
| **Nov (w3–4)** | **Last-order-date sequence begins** | THE revenue send of the year for made-to-order. State real cutoff dates only — get them from dispatch before writing |
| **Dec (w1–2)** | Last-order countdown (genuine deadline = honest urgency) | 2–3 sends; express shipping as the late-buyer safety net |
| **Dec 26–Jan** | Quiet. No "January sale" unless Max wants one | Brand is occasion-led, not discount-led |
| **Late Jan** | Valentine's opener | Mr & Mrs sign + couple pebbles |
| **Early Feb** | Valentine's last-order date | Real cutoff only |
| **Late Feb** | Mother's Day opener (UK date moves — check year) | Big UK gifting moment |
| **Mar** | Mother's Day last-order | |
| **May** | Father's Day opener (mid-June UK) | Football Stadium Sign hero (proven high-AOV) |
| **Jun** | Father's Day last-order + **teacher season opener** | Teacher gifts ran strongly Jun–Jul 2026 |

**Standing rule:** every "last order by X" date must come from actual dispatch
capacity that week — never invented, never padded. A missed promised date costs
more than the campaign earns.
