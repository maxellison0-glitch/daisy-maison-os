# Personalised Reed Diffuser — website image prompts

Turn the raw phone photos into clean, website-ready product images by
**restaging the surroundings only**. Same discipline as the signs: the product
and its label are sacred. Use as **image edits** (reference = the raw photo) in
Higgsfield Nano Banana 2 / Nano Banana Pro (Pro handles fine text best).

## Notes (read before generating)
- **Label fidelity is the risk.** Fine text is where AI editing fails. Generate
  a few cheap takes per shot, then **zoom the label and verify every word** —
  "HOME BY", "DAISY MAISON", the DS monogram, "THE ONE AND ONLY" — before using
  any image. Reject any take that alters the type, exactly like a sign QC.
- Nano Banana **Pro** renders text best; prefer it for shots 1, 4, 5.
  ~2 credits per 2k take.
- For a true macro **label close-up**, prefer a real re-crop of the sharp photo
  over AI — safest text of all.
- **The gift tag reads "Shelby & Sean".** If that's a real customer, treat it as
  PII: keep it for an internal/sample image but re-shoot with a neutral tag
  before any public listing. We never AI-edit the text to change it.
- These restage the *surroundings*; they are honest product images (the real
  product, cleaner room), consistent with the brand's locked
  `projects/social-prompts/PROMPT.md` rule.
