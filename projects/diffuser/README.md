# Daisy Maison — personalised reed diffuser image library

Website/social product images, restaged from clean phone photos by editing
**surroundings only** — the bottle and its label stay pixel-faithful (same
discipline as the signs). Nano Banana Pro, 2k, 4:5. Every take QC'd by zooming
the label; only pixel-faithful text is kept.

## Brand palette (locked 2026-07-24)
**Black · Burgundy · White.** Ribbon colourways: blush, lavender, charcoal,
powder-blue (everyday) + black/burgundy/white glitter (premium/Christmas).
The wedding and Christmas sets use burgundy velvet / winter-wonderland staging;
the DS and Smiths sets are warm-neutral and can be **re-toned to the burgundy
palette** on request for a consistent storefront.

## Label fidelity — the one risk, and how it behaved
Fine label text is where AI editing fails. On the **clean, sharp, red-tinge-free
sources** it held on every bottle-forward hero. It only broke twice, both when
the bottle sits **small** in a gift-lifestyle frame — "H&DE DJ / THE ONE AND
UNTE" and "LEWTYE BY" on a top microline. Both were caught in QC, re-run, and
the clean take kept. Rule: for gift-lifestyle comps, force the label large or
prefer the bottle-forward hero.
