## 📚 Lesson of the Day

### Automated Rules in Facebook Ads Manager

**Callback:** This builds directly on the Ad Set Spend Limits lesson (14 Aug) and the CBO vs ABO lesson (13 Aug). Those lessons explained WHERE to set a budget limit and WHY CBO can override your intent. Today's lesson is the enforcement layer: how to make the ad account police itself when nobody is watching.

An **automated rule** is an instruction you set inside Facebook Ads Manager that checks a condition on a schedule and takes an action automatically — without anyone logging in. Think of it as an if-then statement that runs on Facebook's servers: "IF this campaign's daily spend exceeds £125, THEN pause it" or "IF this ad set's cost per result rises above £15, THEN send me a notification." You create it once, and it fires every time the condition is met.

This matters because the single biggest recurring failure in this ad account is not strategy — it is execution lag. The digest recommended capping TOF-WEDDING at £125/day on 11 August. Seven days later, it spent £247.61 yesterday. The digest recommended pausing EOI-Multiple by Friday 15 August. Two days later, it spent £91.39 yesterday. The total cost of these two unexecuted decisions is approximately £767 in uncontrolled spend over the week. Automated rules exist precisely to prevent this: the rule fires the moment the threshold is crossed, whether Daryl checks Ads Manager that morning or not.

**How to create one:** In Ads Manager, go to the main campaigns/ad sets view. Select the ad set (or campaign) you want the rule on. Click the three-dot menu or the "Rules" dropdown at the top, then "Create a new rule." You get four fields that matter:

1. **Apply rule to:** which campaigns, ad sets, or ads the rule watches. You can apply it to specific ones you select, or to all active ones in the account.

2. **Condition:** the trigger. Facebook offers metrics like Spend (lifetime or daily), Cost per result, CPC, CPM, Frequency, Impressions, and ROAS. For a spending cap, you would set "Lifetime Spend today" greater than £125. For a quality check, "Cost per result" greater than £15. You can combine conditions — "Spend > £125 AND Cost per result > £12" — but keep it simple: one condition, one purpose.

3. **Action:** what happens when the condition is met. Options are **pause** the campaign/ad set/ad, **send notification only** (email), or **adjust budget** (increase/decrease by a percentage or fixed amount). For the TOF-WEDDING cap, the action is "Pause ad set." For a monitoring rule, "Notification only." Never use "Adjust budget" on a rule you have not tested — an increase rule that fires every 30 minutes can double your budget in a day.

4. **Schedule:** how often Facebook checks the condition. Options are "Continuously" (every 30 minutes), "Daily" (once per day at a time you choose), or "Custom" (specific days/times). "Continuously" is the safest for a spend cap because it catches the overspend within 30 minutes rather than letting a full day pass.

**The failure modes to know about:**

The 30-minute check interval means a rule set to "pause when daily spend exceeds £125" will actually let the ad set spend up to about £130–140 before the next check fires. Facebook does not guarantee instant enforcement — the check is periodic. This is fine for a £125 cap but would be a problem for a very tight limit on high-spend campaigns.

A rule that pauses an ad set does not un-pause it the next day. If you pause TOF-WEDDING when it hits £125 today, it stays paused tomorrow. You would need a second rule — "Turn on ad set daily at 00:00" — to restart it each day. The pair of rules (pause at cap + restart daily) is the standard pattern for a daily spend hard-cap on an ad set inside a CBO campaign, because it enforces what an ad set spend limit should do but CBO sometimes overrides.

Rules apply to the level you select. A rule on a **campaign** watches and acts on the entire campaign. A rule on an **ad set** watches only that ad set. If TOF-WEDDING is one ad set inside a CBO campaign shared with TEST OCT 2022 and EOI-Multiple, a campaign-level pause would kill everything. An ad-set-level rule targets only TOF-WEDDING and leaves the others running.

**Worked example with yesterday's numbers:**

TOF-WEDDING spent £247.61 on 16 Aug. If an automated rule had been set on 11 Aug as: "Apply to: TOF-WEDDING ad set. Condition: Lifetime Spend today > £125. Action: Pause ad set. Schedule: Continuously" — the rule would have checked every 30 minutes. By roughly mid-afternoon each day, when TOF-WEDDING crossed £125, the rule would have paused it. Over seven days (11–16 Aug), TOF-WEDDING spent approximately £1,485 total. With the rule enforced, it would have spent approximately £875 (£125 × 7). The £610 difference bought 2,440 additional cheap clicks (at £0.25 CPC) that fed the pixel pool but generated progressively less revenue per pound — the definition of diminishing returns from the 28 Jul lesson.

The same logic applies to EOI-Multiple, but simpler: a one-time rule of "Condition: Always true. Action: Pause. Schedule: Run once on 15 Aug" would have stopped it on deadline. Or just pause it manually — a rule is overkill for a one-time pause, but knowing rules exist means the next deadline gets automated rather than forgotten.
