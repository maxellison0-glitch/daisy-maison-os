## 📚 Lesson of the Day

**Google Ads Experiments — how to test a change without betting the account on it.** This builds on Smart Bidding / Target ROAS and PMax rebuilds. An *experiment* (Google Ads → Campaigns → Experiments) clones a live campaign and splits its traffic, usually 50/50: one half keeps the current settings (the *control*) and the other runs your one change, such as a new tROAS target (the *treatment*). Because both halves bid in the same auctions on the same days, a seasonal dip or bad weekend hits both equally. The difference between them is therefore the effect of your change, which a before/after comparison can never show. The failure mode looks like this account right now: "Target ROAS experiment – DTD KEY OCCASIONS - UPDATE" is Enabled and spent £0.00 yesterday, against £311.70 on the two live campaigns. The "DTD KEY OCCASION" campaign it appears to be built from is Paused, so the experiment looks like it has no traffic to split and is measuring nothing. An experiment is only readable after roughly 2–4 weeks with enough conversions in each arm. At PMAX AUG's 352 clicks a day and a 50/50 split, each arm gets about 176 clicks a day. **Ask Daryl this:** "The DTD KEY OCCASIONS tROAS experiment is enabled but spending nothing. Is it abandoned, and if we wanted to test a higher tROAS on PMAX AUG, would you run it as a 50/50 experiment or just change the target?" A good answer is "an experiment, 50/50, read after X conversions". An evasive one is "I'll just adjust it and watch". TikTok's equivalent is Split Test in TikTok Ads Manager. **You should now be able to** set up a controlled Google test yourself, and spot an experiment that is enabled but dead.
