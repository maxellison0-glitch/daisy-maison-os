## 📚 Lesson of the Day

### Ad Set Spend Limits — Enforcing Budget Control Inside CBO

**Builds on:** Yesterday you learned the difference between Campaign Budget Optimization (CBO) and Ad Set Budget Optimization (ABO) — where the budget lives (campaign level vs ad set level) and why that matters for diagnosing an overspend. The question that lesson left open was practical: if TOF-WEDDING is an ad set inside a CBO campaign, how do you actually enforce a £125/day cap when Facebook's algorithm wants to spend more? Today answers that.

**What ad set spend limits are.** When a campaign runs CBO, Facebook distributes the campaign's daily budget across all its ad sets automatically, chasing the cheapest conversions. You do not directly control how much each ad set gets — the algorithm decides. But Facebook provides a manual override called an ad set spend limit. This is a minimum and/or maximum daily amount you can set on an individual ad set within a CBO campaign. A minimum says "spend at least £X/day on this ad set, even if this audience looks expensive." A maximum says "spend no more than £Y/day on this ad set, no matter how cheap the clicks look." You can set either one, both, or neither.

**Where to find them in Ads Manager.** Open the campaign, click the ad set you want to cap, and look under "Budget & Schedule." Within a CBO campaign, you will see a toggle labelled "Ad Set Spend Limits." Turn it on and two fields appear: minimum daily spend and maximum daily spend. This toggle does not exist in ABO campaigns — in ABO, the ad set already has its own independent budget, so there is nothing to override.

**Why CBO without limits goes wrong — three failure modes.** CBO optimises for the cheapest available conversion across all ad sets. In theory this is efficient. In practice it produces three problems you need to recognise from the outside:

First, audience-size hoarding. A top-of-funnel ad set targeting "UK women 25–55 interested in gifts" has millions of people in it. Facebook can always find another cheap impression, so it keeps spending. The CPC stays at £0.30, the dashboard reports efficient delivery, but each additional person reached is slightly less likely to buy than the last. This is the diminishing returns mechanism from the 28 Jul lesson, except it is happening inside one campaign's budget allocation rather than across the whole account.

Second, starvation. A smaller high-converting audience — say, a retargeting pool of 3,000 recent site visitors — might need only £20/day to reach everyone in it. But CBO might give it £5 because the TOF audience is "bigger" and its CPM is "lower." The high-quality audience gets underfunded while cheap clicks absorb the budget.

Third, the recommendation gap. This digest has said "TOF-WEDDING at £125/day" for four consecutive days. But if TOF-WEDDING is an ad set inside a CBO campaign with a £400/day campaign budget, the recommendation is unenforceable. There is no mechanism making it happen. Facebook will spend whatever the algorithm chooses, up to the full campaign budget. The only way to enforce £125/day on that ad set is to set a maximum ad set spend limit of £125.

**Worked example.** TOF-WEDDING spent £187.49 yesterday. It has now exceeded the recommended £125 for at least four consecutive days: 11 Aug £225.27, 12 Aug £186.44, 13 Aug £187.49. The cumulative overspend across those three days alone: (£225.27 + £186.44 + £187.49) minus (£125 × 3) = **£224.20** above recommendation. What did that £224 buy? At yesterday's blended 2.52x, proportionally about £565 in total sales. But marginal ROAS on overspend is almost always worse than the blend — the first £125 catches the best prospects, and every pound above it buys progressively weaker ones. If the marginal ROAS on the excess was 1.5x (generous), it generated roughly £336 on £224 — a £112 contribution before product costs. At approximately 60% gross margin, that is £67 of gross profit against £224 of ad spend. The overspend lost about **£157 in three days**. That is the cost of a recommendation without an enforcement mechanism.

**What failure looks like from the outside.** You set a £125 maximum and delivery drops to near-zero. This actually tells you something valuable: the audience was already exhausted at the previous higher spend, and at £125 Facebook cannot find enough people worth bidding on. The fix is new creative or a fresh audience definition, not more money. Conversely, if delivery stays healthy at £125 and ROAS improves, you have confirmed the overspend was waste.

**TikTok equivalent.** TikTok's ad group (their name for ad set) carries a direct daily budget in both CBO and non-CBO modes. The mechanic is simpler — every ad group has its own budget number — but the principle is the same: spend control at the targeting level is where enforcement lives.

**Ask Daryl this:** "Can you show me the campaign structure — is TOF-WEDDING its own ABO campaign, or an ad set inside a shared CBO campaign? If CBO, what is the campaign-level daily budget and does TOF-WEDDING have an ad set spend limit set? If not, can you set a £125/day maximum on it today?" A good answer names the exact structure and confirms the change. An evasive answer talks about "letting the algorithm optimise" without showing you the dashboard — that is avoiding the mechanical question.

**You should now be able to:** set or request a specific ad set spend limit on any Facebook ad set inside a CBO campaign, explain why an ad set spend limit is the only tool that makes a budget recommendation enforceable within CBO, and diagnose whether TOF-WEDDING's persistent overspend is a CBO reallocation problem or a standalone budget problem.
