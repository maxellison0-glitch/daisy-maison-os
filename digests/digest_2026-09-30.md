## 📚 Lesson of the Day

**Significant edits — what knocks a Facebook campaign back into learning, and what pausing one ad set inside CBO actually does.** This builds on the learning phase (6 Jun) and the breakdown effect (27 Sep).

- **What a significant edit is.** It is any change big enough that Facebook throws away its current model of who converts and starts learning again. The main ones are:
  - changing targeting, creative, the optimisation event or the bid strategy
  - adding a new ad
  - restarting an ad set that has been paused for 7+ days
  - making a large budget move. Meta doesn't publish a number, but ~20% is the practitioner rule.
- **What it looks like from outside.** The status reads "Learning" again and CPP swings wildly for 3–5 days.
- **Pausing an ad set inside CBO.** CBO means the budget is set at campaign level. Pausing an ad set doesn't save that ad set's money. It hands the money to the siblings that are still on. The breakdown effect already showed those siblings are the ones Facebook had been rationing, because their next purchase was dearer.

Worked example from yesterday:
1. TOF-WEDDING went from £200 to £75, a −62.5% cut. That is about 3× the 20% step, so it is almost certainly a reset.
2. TOF-MAIN was paused. It is gone after its £32.25 on Tuesday, leaving £75 of budget for 2 ad sets.
3. On Tuesday, test_creatives had a £0.84 CPC and 0 purchases, and test_creatives_2 had a £23.70 CPP.

The cheapest-looking ad set was switched off and the budget now flows to the two that were weaker on Tuesday. Two significant edits on the same day also mean you can't tell which one caused whatever happens next.

**Ask Daryl this:** "Why cut TOF-WEDDING by 62% and pause TOF-MAIN in the same move, rather than stepping down ~20% a day, and which of the two changes should we be reading this week?" A good answer names one primary change and a date to judge it. An evasive one is "the algorithm will sort it out."

TikTok treats big budget and bid edits the same way: its ad groups re-enter learning after large changes.

**You should now be able to** spot when a set of changes will reset learning, and ask for changes to be made one at a time so each can be read.
